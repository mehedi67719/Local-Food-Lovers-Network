## Local Food Lovers Network

A full-stack MERN application connecting food lovers to explore local restaurants, street food, and home-cooked meals.

**Live Site:   https://food-lovers-450c0.web.app/

---

##  Features
- User authentication with Email/Password and Google
- Add, edit, delete, and view reviews for foods
- Top-rated reviews displayed on homepage
- Favorite system for logged-in users
- Responsive design for all devices
- Search functionality for all reviews
- Loading spinners / skeletons while fetching data
- 404 error page with “Back to Home” button
- Custom toast messages for errors and success

---

## Technologies Used
- React.js, Tailwind CSS
- Node.js, Express.js
- MongoDB, Mongoose
- Firebase Authentication (Email/Password + Google)
- Optional: React Hook Form, TanStack Query

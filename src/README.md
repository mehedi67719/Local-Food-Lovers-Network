# Local Food Lovers Network

A full-stack MERN application connecting food lovers to explore local restaurants, street food, and home-cooked meals.




# Features
- User authentication with Email/Password and Google
- Add, edit, delete, and view reviews for foods
- Top-rated reviews on homepage
- Favorite system for logged-in users
- Responsive design for all devices
- Search functionality for all reviews

# Technologies Used
- React.js, Tailwind CSS
- Node.js, Express.js
- MongoDB
- Firebase Authentication

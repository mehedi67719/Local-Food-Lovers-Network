## 🍽️ Discover. Share. Enjoy Local Food.

A modern MERN-based community platform where users explore food, post reviews, save favorites, and enjoy an engaging foodie experience.

---

## 🚀 Project Overview

Local Food Lovers Network is a full-stack MERN application designed to connect food lovers who enjoy discovering restaurants, street food, and homemade dishes.  
The frontend is built using **React**, focusing on responsive design, smooth navigation, and clean UI/UX.

---

## ⭐ Features (Client Side)

### 🎨 Modern, Responsive UI
- Clean foodie-themed design  
- Fully responsive for mobile, tablet, and desktop  
- Consistent typography and card layouts  

### 🔐 Firebase Authentication
- Email/Password login  
- Google login  
- Protected routes with persistence  
- User avatar with dropdown options  

### 📝 Review System (CRUD)
- Add new review  
- View all reviews sorted by date  
- Edit your review  
- Delete your review  
- View review details  

### ❤️ Favorite System
- Add to favorites  
- View favorites in separate page  

### 🔍 Search System
- Search by food name  
- Server-side filtering using MongoDB regex  

### 🧭 Smooth User Experience
- Hero slider on home page  
- Toast notifications (no default alerts)  
- 404 Page with “Back to Home”  

---
